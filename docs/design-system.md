# Dino Deets — Design System

## Brand Identity
- **Name:** Dino Deets (Dinosaur Deets with Devaansh)
- **Tagline:** "Where curious minds travel through prehistoric worlds"
- **Tone:** Educational, playful, adventurous, kid-friendly
- **Aesthetic:** "Prehistoric Meets Modern" — dark mode, earthy textures, fossil motifs

## Color Palette

### Primary Colors
| Token | Hex | Usage |
|-------|-----|-------|
| `--color-bg-primary` | `#0E1A16` | Main background (Deep Earth) |
| `--color-bg-secondary` | `#142420` | Cards, sections |
| `--color-bg-tertiary` | `#1A3C34` | Elevated surfaces |
| `--color-surface` | `#1E2D28` | Interactive surfaces |

### Accent Colors

## Typography
- **Display/Headlines:** Titan One (Google Fonts) — bold, carved-in-stone feel
- **Body:** Nunito (Google Fonts) — friendly, rounded, kid-readable
- **Mono/Accents:** Caveat (Google Fonts) — handwritten annotations

## Spacing Scale
`4px → 8px → 12px → 16px → 24px → 32px → 48px → 64px → 96px → 128px`

## Border Radius
- Cards: `16px`
- Buttons: `12px`
- Small elements: `8px`
- Circles: `50%`

## Animation Principles
- Duration: 200ms (micro), 400ms (standard), 800ms (dramatic)
- Easing: `cubic-bezier(0.34, 1.56, 0.64, 1)` for playful bounce
- Scroll animations: fade-up with stagger
