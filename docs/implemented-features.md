# Implemented Features

This document serves as a living log of what has been built and completed for the Dino Deets website so far.

## Core Framework
- [x] Initialized Vite static build.
- [x] Set up basic GitHub Pages hosting architecture.

## UI/UX
- [x] Dark mode default ("Night at the Museum" vibe) established in CSS.

## Features
- [x] **Animated Dino Mascot**: Rebuilt from a static image to a living SVG. Supports eye-tracking (follows the mouse cursor), random blinking, idle behavior (watching a fly), and click interactions (making a cute roar and smiling wider).
- [x] **Dino Encyclopedia & Dedicated Details**: Implemented a gallery view of dinosaurs categorized by geological period. Created a dedicated detail page (`explore/dino-detail.html`) using dynamic search query parameters (`?dino=Name`) to render high-fidelity dinosaur stats, diet, weight, location, and overview bio blocks.
- [x] **Dino Origins & Extinction Story Pages**: Added pages detailing dinosaur origins and extinction. Styled headers, hero images, reading paragraph flow, and back-navigation links to be top-aligned and center-formatted, matching the design of the details page.
- [x] **Dino Discovery Map**: Built an interactive vector world map (`explore/dino-map.html`) utilizing SVG. Dinos are dynamically mapped to accurate geographic coordinates, and users can click glowing nodes to view all dinosaurs discovered at that precise location in a side panel.
- [x] **Footer Synchronization**: Standardized the footer across all website pages to include social links for YouTube, Instagram, and Facebook.
- [x] **Separated JSON Data Architecture**: Split the single massive `dino-data.json` file into ten domain-specific JSON files (e.g. `encyclopedia.json`, `quiz.json`, `random-deet.json`, etc.) to optimize data loading, reduce bundle chunks size, and improve clean separation of concerns.
- [x] **Mascot Linked to Random Facts**: Linked the mascot companion to load and display random facts from `random-deet.json` inside its speech bubble on click. Configured click propagation rules to prevent bubble clicks from accidentally triggering new facts, and removed the deprecated "Random Dino Deet" homepage CTA button.
- [x] **Mascot Speech Bubble & Reaction Enhancements**: Implemented dynamic bubble behavior. Double-tapping the mascot triggers a dizzy animation with brief, randomized text reactions (e.g., "Ouch!", "Bonk!", "Oops!") that auto-hide in 3-seconds, with double-tap separation filtering to prevent single-click facts from briefly firing. Idle states trigger navigation tips that auto-hide in 10-seconds. Click-triggered facts auto-hide in 20-seconds and display a custom close button checkmark. The speech bubble's layout is updated to auto-adjust its width dynamically (`width: fit-content`) with `min-width: 80px` and custom responsive `max-width` limits based on the message type (dizzy/tip messages are capped at 200px on mobile/300px on desktop to remain compact, while detailed "deet" facts can grow wider up to 260px on mobile/480px on desktop for better readability).
- [x] **Fossil Dig Game (v8)**: Developed an interactive mini-game (`games/fossil-dig.html`) where users search the globe under a 1-minute time limit to find 5 target dinosaurs. Features a center-stage introduction screen explaining instructions and combo multipliers. Once started, sequentially populating bouncy markers (`cubic-bezier(0.175, 0.885, 0.45, 1.4)`) spawn on a lazy-tinted world biome map. Excavation lens (450px) overlays display custom biome textures where players scratch to reveal desaturated remains that transition to full color. Successfully excavating a target dinosaur consecutively builds a Combo Multiplier (1x to 5x), awarding `1,000 * streak` points, while digging a non-target dinosaur resets it to 0. Displays a floating glassmorphic next-step tip badge (`z-index: 100`, `pointer-events: none`) that guides users contextually and fades out dynamically once scratch work begins. Synthesizes arcade audio context sound effects (start arpeggios, ticks, target chimes, failure buzzes, time-up sirens). Completing the excavation awards a `100 pts/sec` time bonus and outputs a detailed score breakdown. Fixed reference scoping, border clipping, repeat clicking duplicates, re-entry dragging, and full-circle boundary fill.
- [x] **WebP Image Optimization & Transparency Preservation (v9)**: Converted all 89 local PNG, JPG, and JPEG images in the `public/images/` directory recursively to the `.webp` format with `quality=85` using Pillow. Preserved transparency channel (`RGBA`) for transparent assets (`mascot.webp` and `logo.webp`) and saved opaque assets in the smaller `RGB` format. Updated all references across the codebase (21 HTML, JS, JSON, and CSS files) and deleted the original non-optimized files.
- [x] **Dino Encyclopedia Sizing & Text Scaling (v10)**: Increased dinosaur tile minimum width from `150px` to `180px` (with max width adjusted to `220px`) to prevent name clipping. Implemented container query-based responsive text scaling (`clamp(0.95rem, 9cqw, 1.1rem)`) for the dinosaur name, ensuring long names dynamically scale down cleanly on smaller cards.
- [x] **A Paleontologist's Guide Page & Story Expansion (v10)**: Created a new detailed, kid-friendly "A Paleontologist's Guide" page (`explore/paleo-guide.html`) explaining key paleontology processes (finding, excavating, dating, and reconstructing fossils) across 8 structured cards. Expanded both the existing "Dino Origins" and "The End of an Era" pages to match the guide's level of detail, using newly generated, high-fidelity cover illustrations.
- [x] **Dino Timeline Page & Sub-Period Groupings (v11)**: Refactored the prehistoric timeline page (`explore/dino-timeline.html`) to a compact vertical-scrolling layout. Features nested geological Eras (Triassic, Jurassic, Cretaceous), detailed sub-periods (Early, Middle, Late), and custom stratigraphic columns representing geologic stage names vertically (matching textbook geological charts). The page's scrollbar is styled as a custom geological strata/sedimentary layer vertical indicator with tick marks. Dinosaurs are displayed as circular icons with interactive speech bubble tooltips colored matching their era, with clicking linking to their encyclopedia details. Removed the "Back to Encyclopedia" button.
- [x] **Dino-o-Meter Size Comparison (v12)**: Developed an interactive size comparison workspace (`explore/dino-meter.html`) comparing dinosaurs against a human silhouette. Features an aspect-ratio-preserving, auto-zooming scaling board with absolute-positioned dinosaur cutouts aligned on the ground. Includes dynamic grid axis indicators (vertical/horizontal) and comparison calculations (e.g. *"The Tyrannosaurus Rex was 2.2x taller than a human"*). Refactored selected slots to a clean horizontal layout above the scale board (collapsing to a column on mobile), standardized T-Rex to its full name "Tyrannosaurus Rex", generated a clean text-free Triceratops profile (v2), migrated data to load directly from the main `encyclopedia.json` database, and deleted the duplicate `dino-meter.json` file. Added six new dinosaurs (**Ankylosaurus**, **Spinosaurus**, **Carnotaurus**, **Allosaurus**, **Diplodocus**, and **Parasaurolophus**) to bring the selection list to 13 choices. Fixed vertical ground alignment by configuring `object-position: bottom` on scaled entities, resolved scale height accuracy by setting `width: auto` to prevent aspect ratio distortion from compressing entity heights, resolved leg gap matte issues by globally scanning and clearing chroma-key green pixels, and fixed tooltip/info text clipping by introducing vertical scaling headroom and boundary-aware positioning.
- [x] **Green Chroma-Key Despilling & Image Processing Integration (v13)**: Built and executed a desaturation/despill color correction script (`scripts/suppress_green_spill.py`) to globally identify and suppress green chroma-key reflections from all 78 dinosaur profile WebP images. Capped dominant green pixels where `g > r` and `g > b` to `max(r, b)` to remove green edges and reflections. Integrated this despill algorithm directly into `scripts/process_new_profiles.py` to ensure all future profile assets are automatically despilled during matte removal and conversion. Regenerated and processed strict left-facing profiles for **Sinosauropteryx**, **Edmontosaurus**, **Gorgosaurus**, **Muttaburrasaurus**, **Nodosaurus**, **Procompsognathus**, **Spinosaurus**, **Utahraptor**, and **Pteranodon** (corrected to have exactly two wings). Styled the search input in the dinosaur selection picker modal to match the dark prehistoric aesthetic of the website (adding glowing amber focus borders and a translucent dark background). Replaced the complex drop-shadow colored hover glow with a high-performance, responsive dashed bounding box frame (`border-color` matching the dinosaur's custom scale color) and image brightness adjustment to prevent render lag or edge clipping on hover release.
- [x] **Dino Creator Removal & Navigation Cleanups (v14)**: Removed the Dino Creator page and deleted all associated assets (`dino-creator.html`, `dino-creator.json`, and related `main.js`/`style.css` logic). Removed the Dino Creator link from the Games dropdown and the Paleo Guide link from the Explore dropdown. Removed the "Back to Encyclopedia" buttons from all story detail pages (`origins.html`, `extinction.html`, `paleo-guide.html`, `dino-detail.html`). Optimized the Dinosaur Detail page top padding to exactly `80px` (by setting `.dino-detail-section` top padding to `0` and overriding `.dino-detail-page:not(.origin-page)` to `80px`), while preserving the correct `100px` top padding on the story pages (`origins.html`, `extinction.html`, and `paleo-guide.html`). Improved the navigation dropdown submenus to look premium and sleek by setting menu links as full-width block elements and animating left-padding shift instead of translation on hover.
- [x] **Accurate Discovery Minimap (v14)**: Replaced the placeholder proxy shape on the Dinosaur Detail page with an accurate, dynamic discovery minimap. The page now fetches the high-fidelity vector world map (`world.svg`) at runtime, styles its landmasses to match the dark prehistoric theme, and projects latitude/longitude coordinates to place pulsing amber pin markers precisely at the discovery site(s) for the current dinosaur (including support for multi-location species).
